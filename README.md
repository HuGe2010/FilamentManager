# FilamentManager
FilamentManager-3D打印耗材管理器

这是一个由AI编写的3D打印耗材管理器项目，采用Html、JS、CSS。文件储存在本地，方便、快捷的为您提供耗材存储管理。

后续会添加更多的功能，也欢迎各位提供建议，可通过huge163you@163.com联系我。

# 如何使用-How to use
  1.下载local版，直接点击index.html文件即可开始使用。

  2.下载docker版
```bash
cd filamgr-docker
# 首次启动（会自动拉取镜像、建表、写入默认预设）
docker compose up -d
```
